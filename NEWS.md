# chRonostatistics 1.0.0

- Prepared the first public release with synchronized package, citation,
  repository, author, affiliation, copyright, and MIT-license metadata.
- Documented and implemented the direct chronological semivariogram, the
  discrete Pitard endpoint correction, the physical-trapezoid alternative,
  the distinction between `V(1)` and `V(1) - V(0)`, analyst-selected cyclic
  contributions, and descriptive engineering limits.
- Separated elapsed-time units from measured-value units and strengthened
  validation across data preparation, component estimation, plotting,
  engineering limits, and the reproducible simulators.
- Added explicit repository and build exclusions for local research material,
  validation material, caches, build products, and development state.
- Refreshed the public examples, vignette, function help, release review, and
  generated package documentation for the 1.0.0 API.
